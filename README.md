## 📖 Description

**🇫🇷 Français**
BAKOME Dashboard est une interface web live qui affiche en temps réel les données du BAKOME AI Terminal. Il présente le **Depth of Market** (déséquilibre acheteurs/vendeurs), les **Footprint Charts** (delta volume), un **scanner multi-paires** (jusqu'à 28 paires), et un résumé du compte trading. Une section sponsors affiche toutes les adresses crypto pour soutenir le projet. Léger, rapide, il tourne sur n'importe quel navigateur. Développé intégralement sur un Pixel 4a 5G à Goma, RDC.

**🇬🇧 English**
BAKOME Dashboard is a live web interface displaying real-time data from the BAKOME AI Terminal. It showcases **Depth of Market** (buyer/seller imbalance), **Footprint Charts** (volume delta), a **multi-pair scanner** (up to 28 pairs), and a trading account summary. A sponsor section displays all crypto addresses to support the project. Lightweight and fast, it runs on any browser. Built entirely on a Pixel 4a 5G in Goma, DRC.

**🇪🇸 Español**
BAKOME Dashboard es una interfaz web en vivo que muestra datos en tiempo real del BAKOME AI Terminal. Presenta **Depth of Market** (desequilibrio comprador/vendedor), **Footprint Charts** (delta de volumen), un **escáner multi-pares** (hasta 28 pares), y un resumen de la cuenta de trading. Una sección de patrocinadores muestra todas las direcciones crypto para apoyar el proyecto. Ligero y rápido, funciona en cualquier navegador. Desarrollado íntegramente en un Pixel 4a 5G en Goma, RDC.

## ⚡ Features / Fonctionnalités / Características

- 📊 **Depth of Market** — déséquilibre acheteurs/vendeurs en temps réel
- 👣 **Footprint Charts** — delta volume, volume profile par prix
- 🔍 **Scanner multi-paires** — surveillance jusqu'à 28 paires
- 💼 **Résumé compte trading** — balance, equity, profit
- 💰 **Section sponsors** — adresses crypto visibles en permanence
- 🌐 **Interface web légère** — fonctionne sur tout navigateur
- 🔗 **Connexion JSON** — lit les données exportées par l'EA MQL5
